Netlify frontend for Student Link Manager

- Edit `app.js` and set `API_BASE` to your deployed backend base URL (e.g. https://my-backend.example.com)
- Build and deploy this folder to Netlify (drag-and-drop or connect to GitHub).

If your backend is hosted at `https://example.com/`, set `API_BASE = 'https://example.com'`.

Note: The backend must enable CORS (the included Flask backend does) and provide the JSON API endpoints at `/api/*`.
